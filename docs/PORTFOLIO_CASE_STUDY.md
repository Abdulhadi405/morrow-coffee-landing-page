# Morrow Coffee House — portfolio case study

## Overview

Morrow Coffee House is a self-initiated fictional café concept created to explore editorial art direction, responsive layout, and accessible interaction design.

## Design objectives

- Create a distinctive, warm visual identity without relying on a generic template.
- Use generous whitespace, expressive serif typography, and a restrained coffee-house palette.
- Make the first viewport communicate the brand and provide clear paths to the menu and visit information.

## Implemented features

- Responsive single-page navigation with an accessible mobile menu.
- Hero, menu, story, experience, visit, FAQ, closing CTA, and footer sections.
- Data-driven featured menu cards and native keyboard-friendly FAQ disclosures.
- Semantic anchors, visible focus states, reduced-motion support, metadata, and a custom favicon.
- Local hero, menu, and café-atmosphere photography with deliberate object positioning, lazy loading, and meaningful alternative text.

## Responsive considerations

The layout switches from editorial multi-column compositions to deliberate mobile stacks. Menu imagery, typography, navigation, touch targets, and copy spacing are adjusted for small screens rather than simply scaled down.

## Limitations

This is not client work and does not represent a real café. Its location, hours, menu, prices, and copy are illustrative. It contains no real ordering, booking, map, social account, or contact integrations. The supplied image files have no accompanying source or license metadata; usage rights must be confirmed before publication. No performance or accessibility audit results are claimed here.
