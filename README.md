# Morrow Coffee House

Morrow is a fictional independent café landing page designed as an editorial portfolio concept. It communicates a warm, thoughtful coffee-house identity with responsive layouts, accessible navigation, native FAQ disclosure elements, and supplied café photography.

## Technologies

- React 19 and TypeScript
- Vite
- Tailwind CSS v4 (Vite integration)
- Lucide React
- DM Sans, DM Serif Display, and DM Mono

## Getting started

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Available checks:

```bash
npm run typecheck
npm run lint
npm run build
```

The development server prints a local URL, typically `http://localhost:5173/`. The production output is generated in `dist/` and can be deployed to any static host.

## Limitations

Morrow Coffee House is a self-initiated fictional concept, not a real business or client project. Menu items, prices, hours, and location language are illustrative. There is no ordering, reservation, map, or contact integration.

See the [portfolio case study](docs/PORTFOLIO_CASE_STUDY.md) and [asset credits](ASSET_CREDITS.md).

The supplied image files do not include source, photographer, or license metadata. Confirm image rights before publishing.
